Loop - Escape Room & Laberinto

es una experiencia inmersiva en 3D de tipo *escape room* y laberintos donde tu mejor arma es la mente.
A diferencia de las plataformas habituales de minijuegos, esta propuesta independiente combina acertijos de lógica compleja 
con escenarios que desafían tu percepción espacial. Cada sala y pasillo está diseñado para poner a prueba tu capacidad de análisis,
obligándote a observar los detalles más pequeños para descifrar los patrones ocultos.
Si buscas un reto donde el pensamiento crítico, la deducción , la estrategia y la adrenalina  sean la única vía para romper el ciclo y escapar, 
**Loop** está hecho para ti.
